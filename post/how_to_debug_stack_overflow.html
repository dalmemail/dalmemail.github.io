How to debug a stack overflow

Just use GCC/Clang AddressSanitizer. It works by passing the -fsanitize=address flag to the compiler AND the linker. It should report any issues during runtime. It's not compatible with Valgrind.

When using it to debug something that involves pthread multithreading a message "AddressSanitizer CHECK failed" can happen. To fix just disable use_sigaltstack by setting the shell variable ASAN_OPTIONS=use_sigaltstack=0. See this comment for more info.

If the error "AddressSanitizer:DEADLYSIGNAL" appears (usually multiple times before a segmentation fault) it's caused by the address space layout randomization (ASLR) and disabling it fixes the issue. On Linux this means:

$ echo 0 | sudo tee /proc/sys/kernel/randomize_va_space

Re-enable it once you're done:

$ echo 2 | sudo tee /proc/sys/kernel/randomize_va_space

More info available at StackOverflow.
